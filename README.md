# Machine Learning Application

## Description

Web application developed with Python and Flask to implement and visualize different Machine Learning algorithms.

The project includes applications for Linear Regression, Logistic Regression, and Support Vector Machine (SVM), as well as a basic structure for Reinforcement Learning.

## Technologies Used

- Python
- Flask
- Scikit-learn
- Pandas
- Matplotlib
- Seaborn
- HTML
- CSS
- Bootstrap

## Implemented Algorithms

- Linear Regression
- Logistic Regression
- Support Vector Machine (SVM)
- Reinforcement Learning

## Project Structure

- `app.py`: Main Flask application file.
- `LinearRegression.py`: Linear Regression implementation.
- `LogisticRegression.py`: Logistic Regression implementation.
- `reinforcement_learning.py`: Basic Reinforcement Learning structure.
- `data/`: Contains the datasets used by the application.
- `templates/`: Contains the HTML templates of the application.

## How to Run

To run the application locally, use:

```bash
python app.py
