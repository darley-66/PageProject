Foundations

Machine Learning Concepts

Machine learning uses data to build systems that recognize patterns and make predictions or decisions. Its value depends on the quality of the data, the question being asked, and careful evaluation on examples the model has not seen.

Three learning paradigms

The learning signal determines what the model can discover.

Supervised learning

Training examples include both input features and a known target. The model learns a mapping from inputs to outputs.

Example: Estimate a student's final score from study hours and prior results. Regression predicts a number; classification predicts a category.

Unsupervised learning

Examples have no supplied target. The algorithm searches for structure, such as groups or lower-dimensional representations.

Example: Group retail customers by purchase frequency and spending to explore customer segments.

Reinforcement learning

An agent takes actions in an environment and receives rewards or penalties. It learns a policy that aims to maximize cumulative reward.

Example: A grid-navigation agent learns which moves reach a goal while avoiding obstacles.

A responsible model workflow

1

Define

Specify the decision, target, and success metric.

2

Prepare

Inspect, clean, and split representative data.

3

Train

Fit a model using training data only.

4

Evaluate

Measure performance on held-out data.

5

Monitor

Check reliability as data and conditions change.

Keep test data separate until the final evaluation. Using it during model selection can produce an overly optimistic estimate.

Core vocabulary

Dataset

A collection of observations used for analysis, training, validation, or testing.

Features

Measured input variables supplied to a model, such as study hours or purchase frequency.

Target

The outcome a supervised model learns to predict, such as a score or a spam label.

Model

A parameterized mathematical function fitted to data to support predictions or decisions.

Evaluation depends on the task

Regression

MAE and RMSE express prediction error in target units; R² summarizes variance explained relative to a baseline.

Classification

Precision, recall, F1, and a confusion matrix describe different error types. Accuracy alone can mislead when classes are imbalanced.

Clustering

Silhouette score compares within-cluster cohesion with separation from neighboring clusters. It does not establish that segments are useful to a business.

Benefits and limitations

What machine learning can offer

  • Finds complex patterns in large datasets.
  • Automates repeatable estimates and classifications.
  • Can improve when relevant, representative data becomes available.

What requires care

  • Biased or incomplete data can produce unfair or unreliable outcomes.
  • Strong test performance does not guarantee performance after data drift.
  • Correlation is not evidence of causation, and some models are difficult to interpret.
