Machine Learning Concepts

Basic concepts of Machine Learning

Machine Learning

Machine Learning is a branch of Artificial Intelligence that allows computers to learn from data and make predictions or decisions without being explicitly programmed for every situation.

Dataset

A dataset is a collection of data used to train, test, and evaluate a Machine Learning model.

Features

Features are the characteristics or variables that are used by a Machine Learning model to learn from the data and make predictions.

Model

A model is a mathematical or computational system that learns patterns from data and uses those patterns to make predictions or decisions.

Training

Training is the process of providing data to a Machine Learning model so that it can learn patterns and relationships.

Prediction

Prediction is the process of using a trained model to estimate an outcome based on new or existing data.

Supervised Learning

Supervised Learning uses labeled data, where the expected output is already known, to train a model to make predictions.

Unsupervised Learning

Unsupervised Learning works with data without predefined labels and finds patterns, groups, or relationships within the data.

Testing

Testing is the process of evaluating a trained Machine Learning model using data that was not used during training.

Accuracy

Accuracy measures how well a Machine Learning model performs when making predictions compared with the expected results.
