Reinforcement Learning

Concepts applied to the virtual robot navigation problem

Context of the exercise: In this application, a virtual agent learns how to move through a 10 × 10 environment to reach a target while avoiding walls and danger zones.

Agent

The agent is the virtual robot that interacts with the environment. Its objective is to learn how to reach the target.

Environment

The environment is the 10 × 10 grid where the agent can move through normal cells, avoid walls and enter danger zones.

State

A state represents the current position of the agent. It is represented by its row and column coordinates.

(row, column)

Action

The agent has four possible actions:

  • Up
  • Down
  • Left
  • Right

Reward and Penalty

The agent receives a numerical reward after every action. Positive rewards encourage desirable behavior while negative rewards discourage undesirable behavior.

Situation Meaning
Normal movement Small negative reward
Invalid movement Penalty
Wall Strong penalty
Danger Zone Danger penalty
Target Positive reward

A policy defines which action the agent should take in a particular state. After training, the learned Q-values are used to select the best action.

An episode begins when the agent starts at A and ends when it reaches T or when the maximum number of steps is reached.

Exploration means trying different actions to discover the environment.

Exploitation means choosing the action with the highest estimated Q-value.

The application uses an Epsilon-Greedy strategy to balance both behaviors.

Q-Learning

Q-Learning is a reinforcement learning algorithm that estimates the value of performing an action in a particular state.

The learned value is represented as:

Q(s,a)

The model uses these values to determine which action is expected to produce the best future return.

Important Parameters

Parameter Purpose
Gamma (γ) Determines the importance of future rewards.
Epsilon (ε) Controls the amount of exploration.
Epsilon decay Gradually reduces exploration during training.
Learning rate Controls how strongly new information updates the model.
