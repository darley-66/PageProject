Reinforcement Learning

Learning to Navigate

Concepts connected to the 10 × 10 grid and the SGDRegressor-based Q-learning application.

In this exercise: a robot starts at A, observes its grid position, chooses Up, Down, Left, or Right, and learns from rewards while navigating walls and danger zones toward T.

The interaction loop

Agent

Robot at state (row, column)

Action

Up · Down · Left · Right

Environment

10 × 10 grid with A, T, #, D, and o

Feedback

Reward or penalty updates action values

Repeat the loop until the robot reaches T or the episode reaches its step limit.

Core concepts in this grid

What is Reinforcement Learning?

A learning approach where an agent interacts with an environment, receives feedback, and improves its decisions. Here the agent learns a route through the grid from rewards and penalties.

Agent

The decision-maker: the virtual robot that selects grid movements.

Environment

The 10 × 10 grid. A marks the start, T the goal, # walls, D danger zones, and o ordinary cells.

State

The robot's current location, represented by (row, column).

Action

One of Up, Down, Left, or Right. The transition function keeps the robot in place when a move hits a wall or leaves the grid.

Reward and Penalty

Feedback after a move: ordinary movement costs −1, invalid or wall movement −5, a danger zone −10, and reaching T gives +20.

Policy

The rule for choosing an action in a state. At evaluation time the application chooses the action with the greatest predicted Q-value.

Step

One state-action transition: choose a direction, observe the next state and reward, then update the learned Q estimate.

Episode

One training attempt starting at A. It ends at T or after the 100-step limit.

Experience

The observed tuple (state, action, reward, next_state). The training loop uses each transition immediately to update its action-value model.

Exploration

Trying a random direction to discover outcomes, including alternatives to the currently best-known move.

Exploitation

Choosing the direction with the highest predicted Q-value based on what training has learned so far.

Epsilon-Greedy

With probability ε the agent explores randomly; otherwise it exploits the highest-valued action. In this implementation ε decays after each episode.

Immediate Reward

The reward from the current transition, before considering future rewards. For example, entering a danger cell gives −10 immediately.

Return

The accumulated rewards over a trajectory. The evaluation reports the sum of rewards from its greedy sequence of moves.

Discount Factor (γ)

Controls the weight of future estimates in the update target. The current training code uses γ = 0.95.

State Value V(s)

The expected long-term value of being in a state under a policy. In Q-learning it can be derived from action values as V(s) = maxₐ Q(s,a).

Action Value Q(s,a)

The estimated long-term return for taking action a in state s. The application predicts one value for each of the four directions using SGDRegressor.

Q-Learning

An off-policy method that updates an action value toward the immediate reward plus the discounted best next-state action value. This project approximates Q-values with SGDRegressor.

The training target is the immediate reward plus the discounted best predicted next action value, except when the goal terminates the transition.

target = reward + γ × maxₐ Q(next_state, a) For a terminal goal transition, target = reward.

Training uses epsilon-greedy action selection and reduces ε after each episode. Evaluation uses the greedy action (maximum predicted Q-value) and records state, action, next state, reward, and destination cell type.
