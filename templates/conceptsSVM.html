⚖️ Support Vector Machine (SVM)

Definition

Support Vector Machine (SVM) is a supervised machine learning algorithm used mainly for classification. Its objective is to find a decision boundary that separates different classes while maximizing the distance between the boundary and the closest data points.

Objective in This Application

In this application, SVM is used to classify breast cancer tumors into two categories: malignant or benign. The model uses measurements from the Breast Cancer Wisconsin dataset available through Scikit-learn.

Dataset

The application uses the Breast Cancer Wisconsin dataset provided by Scikit-learn. The dataset contains measurements obtained from breast cancer samples and a target variable indicating whether the tumor is malignant or benign.

Variables Used in the Application

The application receives three measurements from the user:

  • Mean Radius: Average radius of the tumor cells.
  • Mean Texture: Average texture measurement.
  • Mean Perimeter: Average perimeter measurement.

How SVM Works

SVM searches for a decision boundary that separates the observations from the different classes. The closest observations to this boundary are called support vectors and help determine the position of the boundary.

Kernel Used

The SVM model implemented in this application uses a linear kernel.

w · x + b = 0

A linear kernel is appropriate when the model uses a linear decision boundary to separate the classes.

Training Process

  1. The Breast Cancer dataset is loaded from Scikit-learn.
  2. The dataset is divided into training and testing data.
  3. A linear SVM model is created.
  4. The model is trained using the training data.
  5. The model makes predictions using the test data.
  6. The predictions are evaluated using classification metrics.

Classification

The model produces one of two possible classes. In the application, prediction 0 is displayed as Malignant, while prediction 1 is displayed as Benign.

Model Evaluation

The application evaluates the SVM model using several classification metrics.

  • Accuracy: Percentage of correct predictions.
  • Precision: Measures how many predicted positive cases are actually positive.
  • Recall: Measures how many actual positive cases are correctly identified.
  • F1 Score: Combines precision and recall into a single measure.
  • Confusion Matrix: Shows the correct and incorrect classifications made by the model.

Visualization

The application generates a scatter plot using mean radius and mean texture. The points are separated according to their target class, providing a visual representation of the dataset.

Advantages

  • Works well for classification problems.
  • Can work effectively with datasets containing many features.
  • Provides a clear decision boundary between classes.

Limitations

  • The model can require appropriate parameter selection.
  • Results can be affected by the scale of the input variables.
  • The interpretation of the decision boundary can be difficult with many dimensions.
