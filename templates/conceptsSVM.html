⚖️ Support Vector Machine (SVM)

Concepts and fundamentals of SVM

Definition

Support Vector Machines are supervised learning models used for classification and regression tasks. They work by finding the optimal hyperplane that separates data points of different classes with maximum margin.

Key Ideas

  • 📐 Hyperplane: Decision boundary separating classes.
  • 🔑 Support Vectors: Critical data points that define the margin.
  • ⚙️ Kernel Trick: Allows SVM to work in higher dimensions for non-linear separation.

Applications

  • 📧 Spam detection
  • 🩺 Medical diagnosis
  • 📷 Image recognition
  • 🔒 Fraud detection
