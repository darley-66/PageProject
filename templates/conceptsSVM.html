⚖️ Support Vector Machine (SVM)

Concepts, mathematics, and fundamentals of SVM

Definition

Support Vector Machines (SVM) are supervised learning models used for classification and regression. Their main goal is to find the optimal hyperplane that separates data points of different classes with the maximum margin.

The margin is the distance from the decision boundary to the nearest training examples. Those nearest examples are the support vectors; moving other, distant observations often has little effect on the boundary. For regression, the related Support Vector Regression method fits a function while tolerating errors inside a chosen margin or epsilon tube.

Mathematical Formulation

Suppose we have a dataset with points (xᵢ, yᵢ), where xᵢ ∈ ℝⁿ are the features and yᵢ ∈ {+1, -1} are the class labels.

The hyperplane is defined as: w · x + b = 0

The classification rule is: f(x) = sign(w · x + b)

To maximize the margin, SVM solves the following optimization problem:

Minimize: (1/2) ||w||²
Subject to: yᵢ (w · xᵢ + b) ≥ 1, ∀ i

Key Ideas

  • 📐 Hyperplane: The decision boundary separating classes. In 2D it is a line, in 3D a plane, and in higher dimensions a hyperplane.
  • 🔑 Support Vectors: The critical data points closest to the hyperplane. They define the margin and are the most important for the model.
  • ⚙️ Kernel Trick: Technique that allows SVM to classify data that is not linearly separable by mapping it into a higher-dimensional space. Examples:
    • Linear Kernel: K(x, z) = x · z
    • Polynomial Kernel: K(x, z) = (x · z + 1)^d
    • Radial Basis Function (RBF): K(x, z) = exp(-γ ||x - z||²)

Training workflow

Feature scale matters because the margin and many kernels depend on distances. Fit scaling parameters on the training split, then reuse them unchanged on validation and test data.

1

Prepare features

Encode inputs and standardize numeric variables using training data.

2

Choose a kernel

Start with a linear boundary or compare it with an RBF or polynomial kernel.

3

Fit and tune

Select C and, for RBF, γ with validation or cross-validation.

4

Evaluate

Measure relevant errors on held-out data and inspect class-specific results.

Soft Margin SVM

In real-world problems, perfect separation is not always possible. SVM introduces slack variables ξᵢ to allow misclassifications:

Minimize: (1/2) ||w||² + C Σ ξᵢ
Subject to: yᵢ (w · xᵢ + b) ≥ 1 - ξᵢ, ξᵢ ≥ 0

Here, C is a regularization parameter that controls the trade-off between maximizing the margin and minimizing classification errors.

What C controls

A larger C penalizes training errors more strongly and can produce a narrower, more complex boundary. A smaller C permits more violations in exchange for a wider margin.

What γ controls in an RBF kernel

A larger γ makes each training point influence a smaller region, which can create a more detailed boundary. A smaller γ produces smoother, broader influence.

Applications

  • Email filtering: classify a message as spam or legitimate using text features.
  • Medical decision support: separate cases by measured features to help prioritize review; a model is not a diagnosis.
  • Image recognition: classify feature representations when a suitable kernel and training set are available.
  • Fraud screening: flag transactions for further investigation while monitoring false alarms and missed cases.

Advantages

  • Works well with high-dimensional data
  • Effective when the number of features is greater than the number of samples
  • Robust against overfitting, especially with proper kernel choice

Limitations

  • Training can be slow for very large datasets
  • Choice of kernel and parameters (C, γ) is critical
  • Less interpretable compared to simpler models like Logistic Regression
