Unsupervised Machine Learning: K-Means

Customer clustering using centroids and Euclidean distance.

What does K-Means do?

K-Means is an unsupervised algorithm: it groups observations without using a known target label. It assigns each observation to one of K clusters, represented by a centroid (the mean feature vector of the assigned points). The algorithm alternates assignments and centroid updates to reduce the within-cluster sum of squared distances.

Features used in this project

Manual exercise

The exercise uses purchase_frequency and monthly_spending from ecommerce_customers.csv. customer_id identifies a row but is excluded from distance calculations.

The two features are measured on different scales, so spending can dominate Euclidean distance unless features are scaled.

Clustering application

Online Retail transactions are aggregated by customer into PurchaseFrequency, TotalSpending, and AverageSpending. CustomerID remains an identifier, not a model feature.

Spending features use log1p before StandardScaler; displayed centroids are converted back to original units.

In the manual two-feature exercise, each point is assigned to the nearest of three centroids using Euclidean distance:

d(x, c) = √((purchase_frequencyₓ - purchase_frequency_c)² + (monthly_spendingₓ - monthly_spending_c)²)

How the algorithm proceeds

1

Choose K

Set the number of clusters. This project uses K = 3; K-Means does not choose K automatically.

2

Initialize centers

The manual exercise uses predefined centers; Scikit-Learn initializes with k-means++ by default.

3

Assign and update

Assign each point to its nearest center, then recompute each center as its cluster mean.

4

Repeat and assess

Repeat until convergence or an iteration limit; inspect cluster sizes, centers, and validation metrics.

Scaling and centroid interpretation

K-Means relies on distance, so a feature with a larger numeric range can dominate. In the Online Retail application, logarithms reduce the skew of spending values and standardization gives each feature a comparable scale during fitting. A centroid is an average profile in the model's feature space, not necessarily an actual customer.

Silhouette score: values closer to 1 indicate observations are generally closer to their own cluster than to neighboring clusters. A score is a diagnostic, not proof that the segments are meaningful or actionable.

Examples, advantages, and limitations

Where it is used

Retailers explore customer segments; analysts group documents or compress image colors. Results depend on the chosen features and distance measure.

Advantages

  • Simple to implement and explain.
  • Scales well to many observations.
  • Provides compact cluster summaries through centroids.

Limitations

  • Requires K to be selected in advance.
  • Sensitive to scaling, initialization, and outliers.
  • Works best for compact, roughly spherical clusters.
  • Different runs or features can produce different segments.
