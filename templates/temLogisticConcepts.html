📊 Logistic Regression

Definition

Logistic Regression is a supervised machine learning algorithm used for classification problems. Instead of predicting a continuous numerical value, it estimates the probability that an observation belongs to a particular class.

Objective in This Application

In this application, Logistic Regression is used to classify student performance into two categories: risk or no risk. The model determines whether a student is considered at risk based on information from the Student Performance dataset.

Dataset

The application uses the Student_Performance.csv dataset. A risk variable is created from the student's overall score. Students with an overall score below 60 are classified as being at risk.

Variables Used

  • Study Hours: Number of hours used for studying.
  • Attendance Percentage: Percentage of classes attended.
  • Age: Student's age.
  • Risk: Target variable used for classification.

How the Model Works

Assumptions

  • Observations are independent.
  • The dependent variable is categorical.
  • Linear relationship between predictors and log-odds.
  • No strong multicollinearity among predictors.
  • Sufficient sample size for stability.

Model Training Steps

1

Prepare data

Inspect class balance, encode inputs, and scale numeric features when appropriate.

2

Fit coefficients

Use maximum likelihood to estimate coefficients and their effect on log-odds.

3

Choose a threshold

Convert probabilities to class labels using a threshold chosen for the task's error costs.

4

Evaluate

Review the confusion matrix, precision, recall, F1, and ROC-AUC on held-out data.

Interpretation

The model receives study hours, attendance percentage, and age as input variables. Logistic Regression analyzes these values and calculates the probability that the student belongs to the risk class.

Mathematical Foundation

Modern Use Cases

  • Medicine: Disease diagnosis.
  • Finance: Credit scoring.
  • Marketing: Customer churn prediction.
  • Cybersecurity: Spam and fraud detection.
  • Education: Academic performance prediction.
Credit-scoring example: Given variables such as credit amount, repayment duration, and age, a model can estimate the probability of default. A chosen threshold turns that probability into a class; the threshold should reflect the consequences of false approvals and false rejections.

Example

Logistic Regression uses the sigmoid function to convert the model output into a probability between 0 and 1.

P(Y=1) = 1 / (1 + e-z)

The value of z is calculated from the input variables and their coefficients. A probability closer to 1 indicates a higher probability of belonging to the risk class.

Classification

The application uses the model prediction to determine whether the student is classified as being at risk. If the predicted class is 0, the application considers the student approved or without risk. If the predicted class is 1, the student is considered to have default risk.

Training Process

  1. The Student Performance dataset is loaded.
  2. A risk variable is created using the overall score.
  3. The input variables are selected.
  4. The data is divided into training and testing sets.
  5. The Logistic Regression model is trained.
  6. The model predictions are evaluated using test data.

Model Evaluation

The application uses accuracy to evaluate the performance of the Logistic Regression model.

  • Accuracy: Represents the percentage of correct classifications made by the model.

Prediction in the Application

The application allows the user to enter values through the Logistic Regression form. The model then returns a classification and a probability associated with the predicted risk.

Real-World Applications

Logistic Regression can be used for binary classification in areas such as education, finance, medicine, marketing, and cybersecurity.

Importance

Logistic Regression is useful because it is relatively simple to train, provides probability estimates, and is easy to interpret. It is commonly used as a baseline classification algorithm before applying more complex machine learning models.

Advantages and limitations

Advantages

  • Produces probabilities that support threshold-based decisions.
  • Coefficients and odds ratios are relatively interpretable.
  • Efficient to train and useful as a classification baseline.

Limitations

  • Assumes a linear relationship between predictors and log-odds.
  • Correlated predictors can make coefficient estimates unstable.
  • Probability calibration and decision thresholds need validation.
  • Imbalanced classes may require weighting or resampling strategies.
