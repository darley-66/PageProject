📈 Linear Regression

Definition

Linear Regression is a supervised machine learning algorithm used to predict a continuous numerical value based on one or more input variables. In this application, Linear Regression is used to estimate a student's overall score based on the number of study hours.

Objective in This Application

The objective is to analyze the relationship between study hours and students' overall scores. The model learns this relationship from the Student Performance dataset and uses it to estimate the expected score when a user enters a number of study hours.

Dataset

The application uses the Student Performance dataset stored in Student_Performance.csv. The dataset contains 25,000 records with information about students and their academic performance.

Variables Used

  • Independent Variable (X): Study Hours
  • Dependent Variable (Y): Overall Score

How the Model Works

The application reads the study hours and overall score from the dataset. These values are used to train a Linear Regression model. The model finds the line that best represents the relationship between study hours and overall score.

Mathematical Foundation

The basic Linear Regression equation is:

Y = a + bX

  • Y: Predicted overall score.
  • X: Number of study hours.
  • a: Intercept of the regression line.
  • b: Slope of the regression line.

Training Process

  1. The application loads the Student Performance dataset.
  2. The study hours column is selected as the input variable.
  3. The overall score column is selected as the target variable.
  4. A Linear Regression model is trained using these variables.
  5. The trained model is used to predict the overall score.

Prediction

The application allows the user to enter the number of hours studied. After submitting the value, the trained model calculates an estimated overall score.

For example, when entering 5 study hours, the application currently estimates an overall score of approximately 69.91.

Regression Plot

The application generates a graph containing the real data points and the regression line calculated by the model. When a prediction is made, the predicted value is also displayed on the graph.

Model Evaluation

The application displays two evaluation metrics: R² and Mean Squared Error (MSE).

  • R²: Indicates how well the model explains the variation in the target values.
  • MSE: Measures the average squared difference between predicted and actual values.

Real-World Applications

Linear Regression can be used in many areas where a continuous value needs to be predicted. Examples include education, economics, business, engineering, and data analysis.

From question to prediction

For the project dataset, the input is study hours and the target is overall score. A prediction describes the fitted trend; it is not a guarantee for an individual student.

1

Choose variables

Define a measurable predictor, X, and a numeric target, Y.

2

Fit the line

Estimate the intercept and slope by minimizing squared residuals.

3

Inspect residuals

Look for curvature, unequal spread, influential points, and dependence.

4

Test generalization

Evaluate on held-out observations before using the model on new cases.

Advantages and limitations

Advantages

  • Fast to fit and straightforward to explain.
  • Coefficients show the direction and estimated size of an association.
  • Provides a useful baseline for numeric prediction.

Limitations

  • A straight-line model can miss nonlinear relationships.
  • Outliers can strongly affect least-squares estimates.
  • Predictions beyond the observed range are extrapolations and may be unreliable.
  • An association between variables does not establish causation.
