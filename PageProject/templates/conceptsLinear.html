Linear Regression Concepts

What is Linear Regression?

Linear Regression is a supervised learning algorithm used to model the relationship between two quantitative variables. It assumes that the dependent variable (Y) can be predicted from the independent variable (X) using a straight line.

What problems can it solve?

It is mainly used for prediction and trend analysis. For example, predicting grades based on study hours, estimating house prices based on size, or forecasting sales based on advertising investment.

Independent and Dependent Variables
  • Independent Variable (X): The input used to make predictions (e.g., study hours).
  • Dependent Variable (Y): The output we want to predict (e.g., grade).
Relationship between Variables

Linear Regression seeks to find the best-fitting line that minimizes the error between the predicted values and the actual data points.

Regression Line

The regression line is represented by the equation Y = a + bX, where:

  • a: Intercept (value of Y when X = 0).
  • b: Slope (how much Y changes when X increases by 1).

Simple Example

Suppose we analyze the relationship between study hours and grades. If the regression line is Grade = 40 + 5 × Hours, then a student who studies 6 hours is expected to obtain a grade of 70.
